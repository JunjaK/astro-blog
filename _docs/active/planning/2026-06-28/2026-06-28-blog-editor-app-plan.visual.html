7. 보안 (경량 — Cloudflare 뒤, "과하게 X")

노출 — 공개 + 앱 로그인, Cloudflare가 TLS·DDoS·rate-limit·WAF·origin 은닉 처리. 블로그가 이미 CF라 동일 모델 상속. 앱 보안은 아래 4개만.
유지 ① 로그인/세션 — argon2id(Bun.password) + httpOnly 세션 쿠키 + 기본거부 미들웨어. (=기능 자체)
유지 ② 파일/git 코드 올바르게 — slug/category allowlist, path.resolve 컨테인먼트, 셸 금지(execFile). 오버엔지니어링 아님, 버그 안 내는 것.
유지 ③ EXIF/GPS (비용 0) — sharp 기본이 메타 제거 → withMetadata() 안 부르면 끝. 다이어리 GPS 유출 방지.
유지 ④ 빌드 안전망 (공짜) — 잘못된 MDX → CI 실패 → 구 사이트 유지. 배포는 build 성공 게이트.
전부 드롭(과함) — TOTP·brute-force 잠금·자체 HTTPS·fail2ban·systemd 샌드박싱·CSP·vendoring·sandboxed-iframe 미리보기. CF + 위 4개로 끝.
실제 난제(보안 아님) — 한글 IME(조합 중 preventDefault 금지) · MDX 직렬화 충실도(이스케이프+스냅샷) · 레거시 역변환(raw-MDX 폴백) · RPi sharp HEIC(부팅 프로브) · 미참조 미디어 GC.
